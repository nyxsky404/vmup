---
title: JSON output
description: JSON stdout schema for vmup --json on upload and check, including fields for batch id, remote path, and prompt.
icon: Braces
---

Pass `--json` on upload (`vmup …`, `vmup watch`, `vmup --clip`) or `vmup check`. JSON is printed on **stdout**. Human lines, spinner, skip warnings, and the update notice stay off stdout (`--json` suppresses the update notice). Non-TTY stdout/stderr also skip the notice.

`vmup prune --json` (including with `--all`) does not emit this schema.

## Success (upload)

```json
{
  "ok": true,
  "batchId": "agents-20260911-140128-aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee",
  "profile": "default",
  "remotePath": "~/vmup/agents-20260911-140128-aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee/",
  "expiresAt": "2026-09-11T08:36:28.000Z",
  "prompt": "Please inspect all files in ~/vmup/agents-20260911-140128-aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee/",
  "count": 2,
  "files": ["image-01.png", "file-01.pdf"],
  "sweeper": true,
  "sweeperStatus": "current"
}
```

| Field | Type | Notes |
|---|---|---|
| `ok` | boolean | `true` |
| `batchId` | string | Staging / remote directory name |
| `profile` | string | Profile name, or `ssh:<alias>` for `--ssh-host` |
| `remotePath` | string | Always ends with `/` |
| `expiresAt` | string | ISO 8601 timestamp computed by the remote host when the upload finishes |
| `prompt` | string | `prompt_template` with `{{remote_path}}` replaced |
| `count` | number | Staged file count |
| `files` | string[] | **Basenames after rename** (`image-01.png`), not original paths |
| `sweeper` | boolean or omitted | Backward-compatible presence flag: `true` for an executable current or outdated script, `false` when missing; omitted if the status check threw |
| `sweeperStatus` | `current`, `outdated`, `missing`, or omitted | Exact remote sweeper state; omitted if the status check threw |

Pretty-printed with `JSON.stringify(..., null, 2)`.

JSON mode returns after printing the object. It does not copy to the clipboard.

## Success (check)

```json
{
  "ok": true,
  "profile": "default",
  "remoteDir": "~/vmup",
  "sweeper": true,
  "sweeperStatus": "current"
}
```

## Error

```json
{
  "ok": false,
  "error": "SSH preflight failed: …",
  "localStaging": "/Users/you/.cache/vmup/agents-…"
}
```

| Field | When |
|---|---|
| `ok` | Always `false` |
| `error` | Message |
| `localStaging` | SSH/upload failures after a session was created |

Unusable target (no host) errors with `--json` before staging: `{ ok, error }` only, exit 1.

Exit codes are still set. See [Exit codes](/docs/reference/exit-codes).
